Installing, in four clips.

AshtaLok isn't on an app store, so Android asks a few questions first.

  1. Step 1

    Download the file

    Tap Download anyway, then Open.

  2. Step 2

    Allow your browser

    Settings, then Allow from this source.

  3. Step 3

    Install

    Play Protect may ask: More details, Install anyway.

  4. Step 4

    Open AshtaLok

Four steps to get going.

Tick them off as you go. This page keeps nothing; the ticks reset when you leave.

0 of 4 steps done

  1. Tap Turn on protection, then OK on Android's "Connection request". It decides on your phone; your traffic isn't sent to an AshtaLok server. More about the permission

  2. Balanced suits most people. Light breaks least; Strict blocks more. Compare the levels

  3. Allowed lookups go encrypted, to the provider you pick. Plain DNS stays off unless you switch it on. How to choose

  4. Turn it on as Android's Autofill service. Skip it if you're happy with the one you use. Setting up the vault
